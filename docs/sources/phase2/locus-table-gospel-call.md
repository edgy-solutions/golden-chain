# Phase-2 locus table: candidate sources for the gospel-call loci (overnight order item 9)

Document only. Nothing is asserted, minted or ranked.
- **A candidate source** is a work worth reading for that row. It is not a claim about what the work teaches.
- **Warrant rule (the order):** a kind of warrant is recorded only where the source itself claims it. No source below has been read for these rows, except the 1875 Gadsby printing. So the warrant column is "not read" everywhere else.
- **Witness status:**
  - [V] a page image was seen by the build agent;
  - [L] a scan was located by a catalogue lead check (the scan pages were not read);
  - [T] only a web transcript was found, which is not a witness under ADR-0009 Decision 1;
  - [U] unknown.

## Open, for the architect

- **BlackRock and Fulton** have no page witness. Each needs a dated printing before it can be a source (ADR-0009 Decision 1).
- **Brine** has no free scan. The order is to find one or leave Brine out.
- **Hoeksema** is restricted, by the order's own flag ("check copyright"). The CRC 1924 English translation's rights are unknown. The Dutch Acts (1924) are US PD and could be the witness, with any translation made by a person named and signed for.
- **Gill's *Cause of God and Truth***, as distinct from the *Body*, would be a new Source node under ADR-0009.
